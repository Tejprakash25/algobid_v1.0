# ALGOBID Prototype v1.0

## Goal

Validate whether auction-based coding is fun.

## Success Criteria

- 20–50 users try it.
- At least 50% complete one auction.
- At least 30% play a second auction.
- Collect honest feedback.

## Features

- Login
- Virtual Credits
- One Auction Room
- 10 Coding Problems
- Auto Judging
- Leaderboard
